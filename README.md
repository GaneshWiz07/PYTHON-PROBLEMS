## Getting Started 🚀

To get started with the problems in this repository, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/PYTHON-PROBLEMS.git
   ```

2. **Navigate to the directory**:
   ```bash
   cd PYTHON-PROBLEMS
   ```

3. **Run the problems**:
   You can run the Python scripts directly or use an IDE of your choice. 🛠️

## Problems 🧩
